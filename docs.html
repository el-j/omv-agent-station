System Architecture & Overview

Comprehensive technical guide to the 24/7 self-hosted AI orchestrator stack, OpenMediaVault native plugin, LiteLLM gateway, and autonomous dev agent lifecycle.

💡 What is OMV AI Agent Station?
A production-grade, self-hosted AI development powerhouse that turns your OpenMediaVault (OMV 6, 7 & 8) NAS into an always-on autonomous software engineering agent. Dispatch coding tasks, manage git repositories, and query multi-tier LLMs directly via Telegram, Discord, or Signal 24/7.

🏛️ High-Level System Architecture

The stack is engineered around four decoupled layers designed for low memory footprint (120–280MB RAM), resilient multi-model redundancy, and zero-compromise credential security:

📦 Core Stack Components

Component Container / Service Internal Port Purpose & Responsibilities
LiteLLM AI Gateway litellm-proxy 4000 Centralized OpenAI-compatible proxy with dynamic fallbacks, token spend telemetry, and smart router aliases (coder-smart, reasoning-heavy).
Telegram Relay Bot telegram-agent-bot Polling (TLS) 25 interactive commands, native autocomplete (setMyCommands), Forum Topic auto-binding, ForceReply input prompts, and plain-text chat.
Obsidian Second-Brain syncthing 8384 / 22000 Bi-directional peer-to-peer sync for project specs, markdown notes, agent execution logs, and live architecture documentation.
OMV Debian Plugin openmediavault-agent-station OMV Workbench Native settings management, encrypted credential persistence, systemd daemon management, and live health diagnostics.
