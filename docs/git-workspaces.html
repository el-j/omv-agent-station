Git Workspaces & Automated Project Registration

Automated GitHub repository cloning, authenticated PAT credential injection, Obsidian project spec provisioning, and branch workflows.

📂 Fully Automated Project Onboarding:
Whenever you clone or create a repository via the chatbot, the Agent Station automatically registers the directory, injects your PAT token into the git remote, initializes an Obsidian Project Spec file, and creates a Telegram Topic sub-channel!

📥 Cloning Repositories (/clone)

You can clone any public or private GitHub, GitLab, or Bitbucket repository in three seamless ways:

  1. Direct URL Paste: In your private chat with the bot, simply paste any GitHub link (e.g. https://github.com/fastapi/fastapi). The bot automatically detects the git URL and clones it!
  2. Autocomplete Prompt: Tap /clone in Telegram ➔ The bot opens an interactive input placeholder asking for the URL.
  3. One-Line Command: /clone https://github.com/owner/repo [custom-folder-name]

✨ Creating New Remote Repositories (/newrepo)

Create a new remote GitHub repository, initialize local git files, and push the initial commit in one step: 

/newrepo my-awesome-app "Autonomous full-stack web application built on OMV"

The bot creates the repo on your GitHub account, configures .gitignore, README.md, sets the default branch to main, and pushes to origin.

🌿 Git Branch & Diff Workflows

# Check uncommitted git changes:
/diff

# List all local and remote branches:
/branch

# Create and switch to a new feature branch:
/branch feat/user-auth

# Pull latest changes from remote:
/pull

# Push current branch to origin:
/push

🛡️ Automated PAT Authentication

When cloning from GitHub, the bot embeds your configured GITHUB_TOKEN into the git push remote URL: 

https://x-access-token:<GITHUB_PAT>@github.com/owner/repo.git

This allows autonomous agents running in /task or Claude Code CLI to commit and push PR branches without prompting for interactive credentials.
