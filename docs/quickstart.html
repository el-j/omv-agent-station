Quickstart & Installation Guide

Step-by-step installation on OpenMediaVault 6, 7 & 8 using the native 1-click script or Debian .deb package.

✅ Supported Systems:
OpenMediaVault 6 (Debian 11 Bullseye), OpenMediaVault 7 (Debian 12 Bookworm), and OpenMediaVault 8 on x86_64 and ARM64 (Raspberry Pi 4/5).

⚡ Method 1: 1-Click Automated Script (Recommended)

Connect to your OpenMediaVault server via SSH as root and run the single-command installer: 

wget -qO- https://raw.githubusercontent.com/el-j/omv-agent-station/main/scripts/install-plugin.sh | bash

The script automatically performs all of the following steps:

  1. Verifies Debian Bookworm / Bullseye prerequisites (git, python3, wget, docker-compose-plugin).
  2. Builds and installs openmediavault-agent-station_all.deb with native Debian package management.
  3. Compiles OMV Workbench Angular components and registers the Agent Station sidebar menu item.
  4. Provisions secure directory structures with 0600 permission protections.

📦 Method 2: Manual .deb Package Installation

If you prefer downloading the release package directly from GitHub Releases: 

# 1. Download latest release .deb
wget https://github.com/el-j/omv-agent-station/releases/latest/download/openmediavault-agent-station_latest_all.deb

# 2. Install using apt (resolves dependencies automatically)
sudo apt install -y ./openmediavault-agent-station_latest_all.deb

# 3. Reload OMV system services
sudo omv-agent-station apply

🌐 Step 3: WebGUI Setup in OpenMediaVault

After installation, open your OMV WebGUI (e.g. http://192.168.1.200):

  1. Press Cmd+Shift+R or Ctrl+F5 to reload your browser cache.
  2. Navigate to the left navigation menu: Services ➔ Agent Station.
  3. Configure AI Provider Keys:
    • Google Gemini API Key: Get your key free at Google AI Studio.
    • GitHub Token: Add your GitHub Personal Access Token (PAT) with repo & workflow scopes.
  4. Configure Messenger Bot:
    • Paste your Telegram Bot Token (from @BotFather).
    • Enter your personal numeric Telegram User ID (from @userinfobot) for strict authorization.
  5. Click Save and tap the yellow Apply Changes banner!

🖥️ Step 4: Verify Live Service Status

You can inspect the running containers and service health anytime via SSH: 

# Check full status dashboard
omv-agent-station status

# Stream live Telegram bot logs
omv-agent-station logs telegram-bot

# Test LiteLLM proxy health
curl http://localhost:4000/health
