Telegram Bot Handbook & Command Index

Comprehensive reference for all 25 Telegram commands, Forum Topics auto-binding, ForceReply interactive prompts, and natural language chat.

✨ Native Telegram Experience:
The bot implements Telegram's native setMyCommands API with rich icons, ForceReply interactive prompts for mobile devices, and Telegram Supergroup Forum Topics to automatically bind project contexts to dedicated sub-channels.

📋 Full 25-Command Reference Index

Command Syntax & Arguments Description & Action
/chat /chat [-m model] <prompt> Query AI via smart router or specific model (Gemini, Claude, GPT-4o).
/gemini /gemini <prompt> Quick shortcut to query Google Gemini 3.6 Flash.
/gpt4 /gpt4 <prompt> Quick shortcut to query GitHub Models GPT-4o.
/task /task [project] <prompt> Dispatches the autonomous coding agent on the project branch.
/claude /claude <prompt> Executes Anthropic Claude Code CLI on the sandboxed workspace.
/exec /exec <shell-command> Runs shell commands inside /data/workspace safely.
/projects /projects Lists all active workspaces & git repos with interactive action buttons.
/newrepo /newrepo <name> [desc] Creates a remote GitHub repo + clones locally + creates Telegram Topic.
/clone /clone <url> [folder] Clones a git repo with auto-injected PAT credentials & Obsidian specs.
/createtopic /createtopic <project> Spawns a dedicated Telegram Forum Topic for an existing project and binds it.
/bind /bind [project] Binds the current Telegram Topic thread to a workspace project.
/unbind /unbind Unlinks the current topic thread from project context.
/pull /pull [project] Executes git pull --rebase on the project repository.
/push /push [project] [branch] Pushes committed changes to remote repository.
/branch /branch [project] [name] Lists branches or creates/switches to a new feature branch.
/diff /diff [project] Displays uncommitted git diff changes in the project.
/status /status Displays CPU, RAM, disk usage, LiteLLM latency, and tmux sessions.
/models /models Displays active AI model endpoints with interactive buttons.
/modelhelp /modelhelp Detailed guide on context windows, strengths, and recommendations.
/note /note <Title> | <Content> Writes a structured Markdown note to the Obsidian Second-Brain vault.
/vault /vault Lists recent Obsidian notes and project specs synced via Syncthing.
/addcmd /addcmd <name> <template> Creates a dynamic shortcut command (e.g. /addcmd test /exec pytest).
/delcmd /delcmd <name> Deletes a user-defined shortcut command.
/cmds /cmds Lists all user-defined custom commands.
/help /help Interactive handbook and multi-page dashboard.

🧵 Telegram Forum Topics & Multi-Project Channels

When working with multiple repositories, turn your Telegram group into a multi-channel project station:

  1. In Telegram Group Settings ➔ Edit ➔ Turn ON Topics.
  2. Promote the bot to Administrator with Manage Topics permission.
  3. When you run /clone or /newrepo, the bot will automatically create a dedicated sub-channel (e.g. 📂 my-project)!
  4. Inside that topic, you never need to specify the project name in commands — sending /task "Fix auth bug" or /diff automatically executes on that project!
