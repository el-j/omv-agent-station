AI Models, Gateway & Smart Routing

Multi-tier model redundancy, automated fallback cascades, LiteLLM gateway configuration, and model selection syntax.

🧠 Resilient AI Gateway Architecture:
The Agent Station routes all AI queries through a local litellm-proxy container on port 4000. If an upstream provider suffers rate limiting (HTTP 429) or server outages (HTTP 500/503), the gateway seamlessly cascades to the next healthy model in milliseconds with zero dropped messages.

💬 How to Select Models via Chat

You can query any specific model or use intelligent shortcut commands: 

# 1. Quick Shortcut for Google Gemini Flash:
/gemini Explain how systemd timers compare to crond

# 2. Quick Shortcut for GitHub GPT-4o:
/gpt4 Write a TypeScript interface for this JSON schema

# 3. Model Flag Selection via /chat:
/chat -m reasoning-heavy Optimize this SQL join query for 10M rows
/chat -m coder-smart Find and fix the memory leak in worker.py

# 4. Interactive Dashboard:
/models     # Displays active models with tap-to-ask inline action buttons!
/modelhelp  # Displays in-depth model documentation inside chat

🔄 Redundancy & Failover Configuration

The LiteLLM gateway configuration lives in litellm/config.yaml at the root of your Agent Station install, mounted read-only into the litellm-proxy container at /app/config.yaml. The excerpts below are copied verbatim from that file so they can't silently drift from what's actually deployed -- a CI check fails the build if they ever stop matching.

First two deployments of the coder-fast pool (free OpenRouter models are listed first in every router; see Free-Tier Models via OpenRouter below for the full per-router breakdown): 

  - model_name: coder-fast
    litellm_params:
      model: openrouter/nvidia/nemotron-3.5-lightning:free
      api_key: os.environ/OPENROUTER_API_KEY
  - model_name: coder-fast
    litellm_params:
      model: openrouter/poolside/laguna-xs-2.1:free
      api_key: os.environ/OPENROUTER_API_KEY

The router-level settings, applied to every virtual router above:

router_settings:
  routing_strategy: usage-based-routing
  set_verbose: false
  num_retries: 3
  timeout: 120
  retry_after: 5
  cooldown_time: 30 # Cooldown provider for 30s when a 429 occurs
  allowed_fails: 2
  fallbacks:
    - coder-smart: ["gemini-3.7-pro", "gemini-3.7-flash", "github-gpt-4o", "gemini-2.5-flash"]
    - coder-fast: ["gemini-3.7-flash", "gemini-2.5-flash", "github-gpt-4o"]
    - reasoning-heavy: ["gemini-3.7-pro", "github-deepseek-r1", "github-o3-mini", "gemini-3.7-flash"]
    - claude-3-7-sonnet-direct: ["gemini-3.7-pro", "github-gpt-4o", "gemini-3.7-flash"]
    - claude-3-7-sonnet-vertex: ["gemini-3.7-pro", "github-gpt-4o", "gemini-3.7-flash"]
    - gemini-3.7-pro: ["gemini-3.7-flash", "github-gpt-4o", "gemini-2.5-flash"]
    - gemini-3.7-flash: ["gemini-2.5-flash", "github-gpt-4o"]

🆓 Free-Tier Models via OpenRouter

Setting OPENROUTER_API_KEY (get one at openrouter.ai/keys) unlocks a $0-cost tier tried before Gemini/Claude/GPT-4o in every router above. It's optional, purely additive, and safe to enable -- without the key those deployments just fail instantly and the router falls through to the paid tiers exactly as before.
Virtual Router Free OpenRouter Deployments (tried first)
coder-fast nvidia/nemotron-3.5-lightning:free, poolside/laguna-xs-2.1:free
coder-smart poolside/laguna-s-2.1:free, cohere/north-mini-code:free, nvidia/nemotron-3-super-120b-a12b:free
reasoning-heavy z-ai/glm-5.2:free, nvidia/nemotron-3-ultra-550b-a55b:free

Tradeoff: free models carry tighter rate limits and are generally lower quality for hard agentic coding tasks than the paid deployments they sit in front of -- LiteLLM's cooldown logic skips a failing/rate-limited one automatically, so the practical cost is occasionally weaker answers rather than downtime.

This is a point-in-time snapshot: OpenRouter adds and retires free models over time. To re-check what's currently free, query https://openrouter.ai/api/v1/models and filter for entries where pricing.prompt == "0", then compare against litellm/config.yaml.
